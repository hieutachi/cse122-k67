Demo Chương 9 — JS nâng cao: Fetch API và dự án

Chương cuối ghép tất cả lại: lấy dữ liệu từ server bằng fetch + async/await, xử lý đủ ba trạng thái đang tải / thành công / thất bại, và dựng một luồng nghiệp vụ nhiều bước như dự án cuối kỳ.

1. Fetch API: tải dữ liệu thật, xử lý lỗi thật

Nút bên dưới gọi fetch('data/sinh-vien.json') — một request HTTP thật tới chính server đang phục vụ trang này (mở DevTools → Network để thấy nó). Tích “Giả lập lỗi mạng” để yêu cầu một file không tồn tại → nhận 404 → nhánh catch hiện thông báo kèm nút Thử lại.

Xem code async/await

await “dừng” hàm async tới khi fetch xong mà không đơ trang — phần còn lại của trang vẫn chạy bình thường. Đó là khác biệt lớn so với vòng lặp chờ kiểu cũ.

2. Form đặt lịch 3 bước (multi-step) — khung dự án cuối kỳ

Nghiệp vụ thật hiếm khi nằm trong một form duy nhất. Mỗi bước tự kiểm tra trước khi cho đi tiếp; bước cuối ghép dữ liệu thành một payload JSON đúng dạng body của request POST /api/dat-lich (mô phỏng — xem lại chương 1 để nhớ request trông như thế nào).
