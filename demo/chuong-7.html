Demo Chương 7 — Bootstrap Components

Bootstrap là bộ component dựng sẵn: chỉ cần ghép class là có navbar, card, modal, form validation chuẩn production. Demo sống bên dưới nằm trong <iframe> để CSS Bootstrap không lẫn vào CSS của cả site — đúng bài học “cách ly phạm vi ảnh hưởng”.

1. Components chạy thật (Bootstrap 5.3.3 qua CDN)

Khung dưới đây là trang bootstrap-mini.html — thử trực tiếp: thu hẹp trình duyệt xem navbar thành nút hamburger, bấm × để đóng alert, bỏ trống form rồi bấm Gửi để thấy validation, mở modal/accordion/offcanvas. Tất cả hành vi do bootstrap.bundle.min.js đảm nhiệm, không có dòng JS tự viết nào ngoài 5 dòng bật validation.

Trang con cần Internet để tải Bootstrap từ CDN cdn.jsdelivr.net. Không có mạng: cấu trúc HTML vẫn đúng nhưng mất toàn bộ style — bản thân đó là một bài học: CSS đến từ đâu thì giao diện phụ thuộc vào đó.

2. Giải phẫu grid 12 cột & utility classes

Mọi hàng Bootstrap chia thành 12 phần bằng nhau: .col-6 chiếm 6/12 (50%), .col-md-8 chiếm 8/12 từ breakpoint md trở lên. Hình minh hoạ bên phải vẽ bằng CSS thuần (tỉ lệ y hệt) để không phụ thuộc CDN.
