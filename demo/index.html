Demo theo chương

Mỗi chương 2–3 ví dụ giảng dạy “chạy được ngay”: chỉnh thông số, thấy kết quả, đối chiếu code. Nên mở demo trước khi đọc Ebook để có trực giác, rồi quay lại đối chiếu lý thuyết.

Chương 1 · Nhập môn Web, Internet

Giải phẫu URL bằng new URL(); mô phỏng request–response với status 200/301/404/500.

Chương 2 · HTML cơ bản

Mã HTML dựng thành giao diện; máy tính đường dẫn tương đối ../ chống link gãy.

Chương 3 · HTML nâng cao

Bảng điểm colspan/rowspan; form tự kiểm tra bằng HTML5 validation + novalidate.

Chương 4 · CSS cơ bản

Sân chơi selector kèm specificity; trộn màu qua CSS variables với tương phản chữ/nền.

Chương 5 · CSS Layout

Box Model có thanh trượt; sân chơi Flexbox và Grid in ra code CSS theo thời gian thực.

Chương 6 · Responsive & Animation

Giả lập bề rộng thiết bị bằng iframe; phòng thí nghiệm transition và @keyframes.

Chương 7 · Bootstrap Components

Navbar, card, form validation, accordion, modal Bootstrap 5.3.3 chạy trong iframe cách ly + giải phẫu grid 12 cột.

Chương 8 · JavaScript & DOM

Trực quan hoá map/filter/sort/reduce; event delegation; sổ tay localStorage sống sót sau F5.

Chương 9 · Fetch API & dự án

Gọi fetch thật tới JSON với loading/lỗi/thử lại; form đặt lịch 3 bước ghép payload POST.
