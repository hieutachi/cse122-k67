Demo Chương 1 — Nhập môn Web, Internet, môi trường dev

Hai ví dụ nền tảng: đọc hiểu một địa chỉ URL và hình dung chu trình request → xử lý → response giữa trình duyệt với máy chủ web. Cả hai chạy trực tiếp, không cần cài đặt.

1. Giải phẫu một URL

Mọi trang web đều có địa chỉ. Trình duyệt tách địa chỉ thành từng thành phần — protocol, host, port, path, query, fragment — để biết hỏi ai, xin cái gì. Sửa URL bên dưới và xem từng thành phần thay đổi (dùng new URL() của chính trình duyệt).

Fragment (#gioi-thieu) không bao giờ được gửi lên máy chủ — nó chỉ dùng để trình duyệt cuộn tới phần tử có id tương ứng trong trang.

2. Mô phỏng request – response HTTP

Web hoạt động theo mô hình client–server: trình duyệt gửi request (dòng yêu cầu + headers), máy chủ trả về response (status line + headers + body). Chọn method và status rồi bấm gửi để xem thông điệp thô của hai chiều.
