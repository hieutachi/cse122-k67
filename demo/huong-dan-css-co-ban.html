Hướng dẫn sử dụng CSS cơ bản

Tài liệu này tập trung vào cách viết quy tắc CSS và các kỹ thuật định dạng thường dùng, không trình bày lại ba cách chèn CSS.

Cú pháp Bộ chọn Box Model Bố cục Responsive
01

Cú pháp của một quy tắc CSS

Một quy tắc CSS gồm bộ chọn và một khối khai báo. Mỗi khai báo có dạng thuộc-tính: giá-trị;.

p {
  color: #172033;
  font-size: 16px;
  line-height: 1.6;
}

Bộ chọn (selector)

Cho biết phần tử nào sẽ nhận kiểu, ví dụ p, .card hoặc #header.

Thuộc tính và giá trị

color là thuộc tính, còn #172033 là giá trị được gán cho thuộc tính đó.

Mẹo: Mỗi khai báo nên kết thúc bằng dấu chấm phẩy để dễ đọc và tránh lỗi khi thêm dòng mới.

02

Các bộ chọn thường dùng

/* Chọn tất cả thẻ p */
p { color: #334155; }

/* Chọn phần tử có class="notice" */
.notice { background-color: #fef3c7; }

/* Chọn phần tử có id="top" */
#top { padding: 24px; }

/* Chọn p nằm bên trong .article */
.article p { margin-bottom: 16px; }

/* Chọn p ngay sau h2 */
h2 + p { color: #64748b; }

Bộ chọn class thường được ưu tiên trong dự án vì có thể dùng lại cho nhiều phần tử. id nên dành cho một phần tử duy nhất hoặc một điểm neo.

03

Box Model: hộp của phần tử

Mỗi phần tử được xem như một chiếc hộp gồm content, padding, border và margin.

.card {
  width: 280px;
  padding: 20px;
  border: 2px solid #2563eb;
  margin: 24px;
}

Thông thường, width chỉ tính phần content. Dùng box-sizing: border-box để width bao gồm cả padding và border.

Content nằm bên trong padding. Vùng xanh lá là padding, đường cam là border.

04

Màu sắc, chữ và nền

CSS cho phép định dạng màu chữ, màu nền, cỡ chữ, kiểu chữ, căn lề và khoảng cách dòng.

.profile {
  color: #172033;
  background-color: #ffffff;
  font-family: Arial, sans-serif;
  font-size: 18px;
  font-weight: bold;
  text-align: center;
  line-height: 1.5;
}

Nên tạo biến màu trong :root khi một màu được dùng nhiều lần. Khi cần đổi giao diện, chỉ cần sửa giá trị của biến.

:root {
  --primary: #2563eb;
}

.button {
  color: #ffffff;
  background-color: var(--primary);
}
05

Bố cục với Flexbox và Grid

Flexbox phù hợp để sắp xếp các phần tử theo một chiều. Grid phù hợp với bố cục gồm hàng và cột.

Flexbox

.menu {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 16px;
}
ABC

Grid

.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

06

Trạng thái và pseudo-class

Pseudo-class mô tả trạng thái đặc biệt của phần tử, chẳng hạn khi người dùng rê chuột hoặc dùng bàn phím.

.button:hover {
  background-color: #1d4ed8;
}

.button:focus-visible {
  outline: 3px solid #f97316;
  outline-offset: 2px;
}

input:checked + span {
  color: #2563eb;
}
Di chuột hoặc bấm Tab vào đây
07

Responsive cho điện thoại

Media query thay đổi kiểu hiển thị khi chiều rộng màn hình đạt điều kiện nhất định.

.layout {
  display: grid;
  grid-template-columns: 1fr 1fr;
}

@media (max-width: 640px) {
  .layout {
    grid-template-columns: 1fr;
  }
}

Hãy thử thu nhỏ cửa sổ trình duyệt: các ô minh họa phía trên sẽ chuyển từ hai cột thành một cột.

08

Quy trình viết CSS dễ kiểm soát

  1. Xác định đúng phần tử cần định dạng.
  2. Đặt tên class ngắn, rõ nghĩa và dùng dấu gạch ngang.
  3. Viết kiểu chung trước, rồi mới viết kiểu riêng và responsive.
  4. Dùng biến CSS cho màu sắc, khoảng cách và các giá trị lặp lại.
  5. Kiểm tra trên cả màn hình máy tính và điện thoại.

Học CSS bằng cách đọc, sửa giá trị và quan sát kết quả.
