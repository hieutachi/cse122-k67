Demo Chương 5 — CSS Layout: Box Model, Flexbox, Grid

Ba công cụ layout quan trọng nhất của CSS, mỗi thứ một “phòng thí nghiệm” chỉnh thông số thấy kết quả ngay: Box Model (một phần tử chiếm bao nhiêu chỗ), Flexbox (xếp một hàng/cột), Grid (chia lưới hai chiều).

1. Phòng thí nghiệm Box Model

Kéo các thanh trượt để thay 4 lớp của hộp: margin — vàngborder — campadding — xanh lácontent — xanh dương. Bật box-sizing: border-box để thấy width “nuốt” luôn padding + border — lý do mọi dự án hiện đại đều đặt * { box-sizing: border-box }.

content

Công thức content-box (mặc định): chỗ chiếm = width + 2×(padding + border + margin). Với border-box: chỗ chiếm = width + 2×margin, và vùng nội dung thực = width − 2×(padding + border).

2. Sân chơi Flexbox

Flexbox xếp các phần tử theo một trục. Đổi từng thuộc tính và quan sát: flex-direction chọn trục, justify-content chia khoảng cách dọc trục chính, align-items canh trục chéo, gap tạo khe hở. Code CSS bên phải tự cập nhật theo đúng trạng thái đang thấy.

3. Sân chơi CSS Grid

Grid chia mặt phẳng theo hai chiều: grid-template-columns: repeat(n, 1fr) tạo n cột đều nhau, các item tự chảy vào ô. Đổi số cột và gap — số item cũng đổi theo (2 hàng).

Khi nào dùng gì? Flexbox cho một hàng điều hướng, nhóm nút, thẻ nằm ngang. Grid cho bố cục trang, lưới card nhiều hàng nhiều cột. Cả hai thường phối hợp: Grid dựng khung, Flex căn nội dung trong từng ô.
